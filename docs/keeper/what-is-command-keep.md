# What the Command Keep is

Keywords: overview, what can it do, capabilities, system, command centre, command keep

The Command Keep is an operator-controlled AI runtime. You give it work in two ways:

- **Objectives for autonomous agents.** An agent receives a goal and decides its own sequence of thinking and granted actions, within limits, until it judges the goal met.
- **Workflows for known processes.** A workflow is a fixed, linear list of steps, each done by an agent, run in order.

Every model call and every tool action is governed: capability Grants, Policy, budgets, approvals, emergency stops, and an immutable event record. Results are immutable artifacts; documents open as readable deliverables with their evidence and provenance.

The pixel keep is the view. The runtime's rows and events are the truth. Ask the Keeper "what can the Command Keep do right now" to see what is configured.
