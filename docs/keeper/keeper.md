# The Keeper

Keywords: keeper, help, guide, think, ask, tokens, proposal

The Keeper answers questions about the Command Keep. Explanations and guide cards come from the system's own records and these cards, with no model and no token use.

**Think** is different and explicit: it asks the Keeper's agent to reason about your question. That runs as an ordinary governed goal in the Keeper project, on the CHEAP tier, with read-only capabilities, under the usual budgets. The answer is a document you can inspect.

The Keeper never changes anything. When a new agent or workflow would help, it proposes one; the proposal only pre-fills a builder form, and nothing is created until you submit it.
