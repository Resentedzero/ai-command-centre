# Research: what exists and what does not

Keywords: research, search, web, internet, retrieve, fixture, corpus, sources, external

- **research.retrieve** retrieves information already held. Its current binding is either fixture test data or a local document folder. It is never web research.
- **research.search** (discover new external information) and **research.open** (read a discovered source) do not exist yet. They can be added later as capabilities with their own bindings, grants and policy, without changing how agents work.

Deliverables state their evidence basis, so a document never implies current external research that did not happen.
